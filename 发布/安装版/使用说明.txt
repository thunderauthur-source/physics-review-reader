物理复习提纲阅读器 · 单文件版使用说明
版本 v1.0 ｜ 2026-10-24
================================

一、这是什么
------------
一个离线的物理复习阅读器，包含：
· 量子力学：教材 323 页、习题解答 436 页、19 份课件 218 页
· 热力学统计物理：教材 340 页、3 份讲义 219 页
左侧提纲点卡片，右侧直接跳到教材/讲义对应页；支持书签、笔记、
框选高亮、全局搜索、章节目录、阅读进度记忆。
完全离线，不联网，只调用系统里的 Microsoft Edge。

二、第一次使用：先选安装位置
----------------------------
1. 双击「物理复习提纲阅读器_v1.0_单文件版.exe」。
   （如果收到的是压缩包，先解压出 exe 再双击。）

2. 会弹出「选择安装位置」窗口：
   · 默认位置是 D:\物理复习提纲阅读器（没有 D 盘时默认“文档”里）；
   · 点「浏览…」可以选择任意文件夹，例如：
         D:\学习\物理复习提纲阅读器
         E:\软件\物理复习提纲阅读器
   · 不建议装在 C:\Program Files，普通文件夹即可。

3. 确认路径后点「开始安装」，等待进度条走完（约 10–20 秒）。
   程序会把全部内容安装到你选的目录，不会偷偷装进 C 盘。

4. 安装完成后会自动：
   · 在桌面创建「物理复习提纲阅读器」快捷方式
   · 打开阅读器窗口

5. 如果 Windows 弹出「Windows 已保护你的电脑」（SmartScreen）：
   点「更多信息」→「仍要运行」。
   这是因为 exe 没有购买代码签名证书，不是病毒。

6. 需要系统里有 Microsoft Edge（Win10 / Win11 自带）。
   如果杀毒软件拦截，请把 exe 加入信任/白名单。

三、以后怎么打开
----------------
· 双击桌面的「物理复习提纲阅读器」快捷方式；
· 或再次双击这个 exe：程序会读取上次安装位置，直接启动，不再询问；
· 安装完成后，exe 本身可以移动或删除，桌面快捷方式仍然可用。

四、想换一个安装位置
--------------------
· 关闭阅读器；
· 在命令行运行：
      物理复习提纲阅读器_v1.0_单文件版.exe --setup
  会重新弹出选择窗口；
· 选新目录安装后，旧目录不会自动删除，确认不需要后手动删掉即可。

五、进度、书签、笔记在哪
------------------------
· 全部保存在你选的安装目录里，例如：
      D:\物理复习提纲阅读器\程序\edgeprofile
· 不要删除这个文件夹，否则进度、书签、笔记、高亮会丢失。
· 备份：阅读器里「学习」→「统计」→「备份学习数据」。
· 换电脑：在新电脑安装后，用「恢复备份」导入 JSON。

六、怎么卸载
------------
1. 关闭阅读器窗口（包括 Edge 应用窗口）。
2. 删除桌面的「物理复习提纲阅读器」快捷方式。
3. 删除你选择的安装文件夹（例如 D:\物理复习提纲阅读器）。
4. 可选：删除注册表项 HKEY_CURRENT_USER\Software\物理复习提纲阅读器
   （只记录安装路径，不删也不影响）。
不写系统服务、不装驱动、不需要管理员权限。

七、常见问题
------------
1. 双击后没反应
   · 看任务栏是否有 SmartScreen 提示，按「更多信息 → 仍要运行」。
   · 确认系统有 Edge；确认磁盘剩余空间大于 250 MB。
   · 第一次安装较慢时，等 20–30 秒。

2. 提示“这个位置不能写入”
   · 换一个普通文件夹（如 D:\物理复习提纲阅读器）；
   · 不要选 C:\Program Files、系统盘根目录或只读目录；
   · 确认当前用户对该文件夹有写权限。

3. 提示“该目录已经安装过阅读器”
   继续会覆盖程序文件，但保留 程序\edgeprofile 里的进度、书签和笔记。

4. 桌面快捷方式图标是白的
   右键 exe → 发送到 → 桌面快捷方式，或刷新桌面（F5）。

5. 页面字太小
   阅读器顶栏「适宽」或「+」放大；也可以拖中间分隔条。

6. 热统 §2.8、§3.6、§3.8 没有讲义链接？
   这三节是补充材料，课堂讲义没有对应页，但「教材」链接可用。
