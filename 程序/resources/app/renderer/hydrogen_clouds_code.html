Common Frame

先搭一个二维截面网格

所有图都采用同一套流程：在 x–z 或 x–y 平面上取网格，算出每一点的波函数，再取模方 |ψ|²。代码中以玻尔半径 a0 = 1 为单位。

  • 左图：概率密度截面，暗处为低概率或节点。
  • 右码：只保留该轨道的波函数与取模方，省略配色、等高线和标尺。
  • 每段代码的 L 与 gamma 是该图实际使用的取景半宽和亮度压缩参数。

完整渲染器（渐变、等高线、标尺）在 构建/生成氢原子电子云.py。本页不依赖 KaTeX，复制即可在 NumPy 环境运行。

common.py 
# 公共网格：xz 平面；3d_xy 改用 xy 平面
import numpy as np

A0 = 1.0  # 长度单位：玻尔半径 a0

x = np.linspace(-L, L, 1000)
X, Z = np.meshgrid(x, x, indexing="xy")
R = np.hypot(X, Z)
THETA = np.arccos(Z / R)

# psi 为下面五个函数之一；取模方后按 gamma 调到适合显示
rho = np.abs(psi(R, THETA))**2
img = (rho / rho.max()) ** gamma

01 · s Orbital

1s 球对称基态

L=3.8 · γ=0.50

基态波函数只有指数衰减，没有节点。代码直接写出归一化函数，再对二维网格取模方。

psi_1s.py 
def psi_1s(r):
    return np.exp(-r / A0) / np.sqrt(np.pi * A0**3)

rho = np.abs(psi_1s(R))**2
# 本图：L=3.8, gamma=0.50, scale=2 a0

02 · s Orbital

2s 带节点壳的球

L=8.2 · γ=0.30

因子 (2 - r/A0) 在 r = 2a₀ 处变号，对应图中亮核与外围壳层之间的暗环。

psi_2s.py 
def psi_2s(r):
    x = r / A0
    return ((2 - x) * np.exp(-x / 2)
            / (4 * np.sqrt(2 * np.pi) * A0**1.5))

rho = np.abs(psi_2s(R))**2
# 本图：L=8.2, gamma=0.30, scale=5 a0

03 · p Orbital

2pz 双瓣哑铃

L=13 · γ=0.48

cos(theta) 在 xy 平面为零，给出中间的角节点；r 因子保证核处波函数为零。

psi_2pz.py 
def psi_2pz(r, theta):
    x = r / A0
    return (x * np.exp(-x / 2) * np.cos(theta)
            / (4 * np.sqrt(2 * np.pi) * A0**1.5))

rho = np.abs(psi_2pz(R, THETA))**2
# 本图：L=13, gamma=0.48, scale=5 a0

04 · d Orbital

3dz² 双瓣 + 环

L=22 · γ=0.52

3*cos(theta)**2 - 1 给出两个锥形角节点。三维里的腰部环，在截面上表现为左右两个小瓣。

psi_3dz2.py 
def psi_3dz2(r, theta):
    x = r / A0
    return ((x**2 * np.exp(-x / 3)
             * (3 * np.cos(theta)**2 - 1))
            / (81 * np.sqrt(6 * np.pi) * A0**1.5))

rho = np.abs(psi_3dz2(R, THETA))**2
# 本图：L=22, gamma=0.52, scale=10 a0

05 · d Orbital

3dxy 四瓣梅花

L=22 · γ=0.52

sin(2*phi) 在 x=0 与 y=0 两个平面为零，把 xy 平面分成四瓣。它是 m = ±2 的实线性组合。

psi_3dxy.py 
def psi_3dxy(r, theta, phi):
    x = r / A0
    return ((x**2 * np.exp(-x / 3)
             * np.sin(theta)**2 * np.sin(2 * phi))
            / (81 * np.sqrt(2 * np.pi) * A0**1.5))

# 本图取 x-y 平面
Y = np.meshgrid(x, x, indexing="xy")[1]
R_XY = np.hypot(X, Y)
PHI = np.arctan2(Y, X)

rho = np.abs(psi_3dxy(R_XY, np.pi / 2, PHI))**2
