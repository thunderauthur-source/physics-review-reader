How to Read

电子云不是电子的轨迹

氢原子的定态由三个量子数 \((n,l,m)\) 标记。空间波函数分离成径向部分与球谐函数：

\[ \psi_{nlm}(r,\theta,\phi)=R_{nl}(r)\,Y_l^m(\theta,\phi), \qquad \mathrm{d}P=|\psi_{nlm}|^2\,r^2\sin\theta\,\mathrm{d}r\,\mathrm{d}\theta\,\mathrm{d}\phi. \]

图中画的是概率密度 \(|\psi|^2\) 的一个二维截面：亮的地方表示电子出现的概率密度高，黑的地方表示密度低或恰好是节点。它不是电子绕核运动的轨道，也不是某一瞬间的“电子位置照片”。

取 \(a_0=0.529\,\text{Å}\) 为长度单位。1s、2s、2pz、3dz² 取 \(x\)–\(z\) 平面；3dxy 取 \(x\)–\(y\) 平面。每个轨道独立归一化亮度，因此不同图之间只比较形状，不比较绝对亮度；各图取景范围也不同，比较尺寸时以左下角标尺为准。

低概率密度高概率密度
标尺：左下角横线标出 \(2a_0\)、\(5a_0\) 或 \(10a_0\)。
节点：概率密度为零的曲面或平面；在截面上表现为暗线或暗环。
径向节点：只与 \(r\) 有关的节点球面；角节点：只与 \(\theta,\phi\) 有关的节面或节锥。
总节点数：\(n-1\)。这是判断轨道“层次”的快速检查。
n=1 · l=0 · m=0x–z 截面

Ground State

1s 球对称基态

−13.6 eV
\[ \psi_{100}(r)=\frac{1}{\sqrt{\pi a_0^3}}e^{-r/a_0}. \]
径向节点 0 角节点 0 最概然半径 \(a_0\)

指数衰减的球形云，没有节点。径向概率 \(4\pi r^2|\psi|^2\) 在 \(r=a_0\) 处达到最大；越靠近核，概率密度越高，但球壳体积元 \(4\pi r^2\mathrm{d}r\) 在 \(r=0\) 处为零。

n=2 · l=0 · m=0x–z 截面

First Excited s

2s 带径向节点的球

−3.40 eV
\[ \psi_{200}(r)=\frac{1}{4\sqrt{2\pi}a_0^{3/2}} \left(2-\frac{r}{a_0}\right)e^{-r/(2a_0)}. \]
径向节点 1 角节点 0 外峰 \(5.24a_0\)

在 \(r=2a_0\) 处有一个球状径向节点，图中央亮区与外围壳层之间的暗环就是它。径向概率有两个峰：内峰约 \(0.76a_0\)，外峰约 \(5.24a_0\)，外峰更高、更宽。

n=2 · l=1 · m=0x–z 截面

p Orbital

2pz 双瓣哑铃

−3.40 eV
\[ \psi_{210}(r,\theta)=\frac{1}{4\sqrt{2\pi}a_0^{3/2}} \frac{r}{a_0}e^{-r/(2a_0)}\cos\theta. \]
径向节点 0 角节点 1 最概然半径 \(4a_0\)

\(x\)–\(y\) 平面（\(\theta=90^\circ\)）是角节点，所以两瓣被中间的暗平面分开。电子云沿 \(z\) 轴伸展，绕 \(z\) 轴旋转对称；它没有径向节点，最概然半径是 \(4a_0\)。

n=3 · l=2 · m=0x–z 截面

d Orbital

3dz² 双瓣 + 环

−1.51 eV
\[ \psi_{320}(r,\theta)=\frac{1}{81\sqrt{6\pi}a_0^{3/2}} \left(\frac{r}{a_0}\right)^2e^{-r/(3a_0)} (3\cos^2\theta-1). \]
径向节点 0 角节点 2 最概然半径 \(9a_0\)

\(3\cos^2\theta-1=0\) 给出两个锥形角节点（\(\theta\approx54.7^\circ,125.3^\circ\)）。三维形状是沿 \(z\) 轴的两大瓣加上腰部的一个环形电子云；在这个 \(x\)–\(z\) 截面上，环被切成左右两个小瓣。

n=3 · l=2 · |m|=2x–y 截面

Real d Orbital

3dxy 四瓣梅花

−1.51 eV
\[ \psi_{3d_{xy}}(r,\theta,\phi)=\frac{1}{81\sqrt{2\pi}a_0^{3/2}} \left(\frac{r}{a_0}\right)^2e^{-r/(3a_0)} \sin^2\theta\,\sin 2\phi. \]
径向节点 0 角节点 2 最概然半径 \(9a_0\) 四瓣

这是 \(m=\pm2\) 两个球谐函数的实线性组合。\(x=0\) 和 \(y=0\) 两个平面是节面，把电子云分成四瓣，瓣的中心沿 \(x\)–\(y\) 平面的对角线方向。它与 \(3d_{z^2}\) 有相同的 \(n,l\) 和能量，只是 \(m\) 与空间取向不同。

五个轨道放在一起看

能量只由 \(n\) 决定；形状和节点由 \(l,m\) 决定。

轨道 \((n,l,m)\) 能量 节点（径向 / 角 / 总） 最概然半径 形状
1s \((1,0,0)\) −13.6 eV 0 / 0 / 0 \(a_0\) 球对称，无节点

2pz \((2,1,0)\) −3.40 eV 0 / 1 / 1 \(4a_0\) 沿 \(z\) 轴的双瓣
3dz² \((3,2,0)\) −1.51 eV 0 / 2 / 2 \(9a_0\) 双瓣 + 腰部环
3dxy \((3,2,\pm2)\) −1.51 eV 0 / 2 / 2 \(9a_0\) \(xy\) 平面四瓣
RADIAL NODES \(n-l-1\)

只与半径 \(r\) 有关；2s 的 \(r=2a_0\) 暗环就是一个例子。

ANGULAR NODES \(l\)

节面、节锥的数量；p 轨道有 1 个，d 轨道有 2 个。

TOTAL NODES \(n-1\)

径向与角节点数之和；可用来快速检查轨道的层次。
