物理复习提纲合集
================

HTML\
  量子力学复习提纲_第1-3章.html
  热力学统计物理_复习提纲_第1-3章.html
  单文件提纲，双击直接打开；不联网，可直接打印。

程序\
  物理复习提纲阅读器.lnk   推荐入口（直接调用已签名的 Edge，避开 SmartScreen）
  QMLauncher.exe.disabled  旧启动器（未签名，Windows 可能拦截，已停用）
  打开阅读器.cmd           备用入口（调用上面的 .lnk）
  阅读器.html              用默认浏览器打开的备用入口
  edgeprofile\             阅读进度/书签/笔记/高亮，勿删
  icon-source.jpeg         图标原图
  resources\app\
    renderer\outline_qm.html      量子力学提纲
    renderer\outline_thermo.html  热统提纲（卡片带教材 + 讲义双链接）
    data\manifest_qm.js           两门课文档/卡片/页码
    data\search_index.js          全局搜索索引
    docs\pages\                   量子力学 977 页 + 热统讲义 219 页 + 教材 340 页

发布\
  安装版\   单文件安装包（首次运行自选安装位置）+ 使用说明
  网页版\   静态网页版（可部署到 Netlify / Cloudflare Pages / GitHub Pages）

使用：
- 左侧顶部「课程」下拉切换：量子力学 / 热力学统计物理。
- 两门课分别记住上次的文档和页码；界面配色也跟着课程走（粉紫 / 青绿）。
- 热统卡片下方有「教材 pp.x–y · 讲义 pp.a–b」：
  · 教材是汪志诚《热力学·统计物理》第六版，PDF 页码 = 印刷页码 + 15；
  · 讲义是三份课堂讲义，页码是 PDF 页。
  · 点「教材」跳教材，点「讲义」跳讲义；右侧「定位卡片」可从任一份回到提纲。
- §2.8、§3.6、§3.8 在讲义里没有对应页，但仍可以从「教材」链接跳到教材。
- 「目录」里现在按文档分组：教材 36 节 + 三份讲义各节，共 69 条。

新增功能：
- 顶栏 ☆：收藏当前页；「学习」抽屉里看书签、笔记、统计。
- 笔记：给当前页写笔记，按课程/文档/页码保存。
- 高亮：点「高亮」进入框选模式，在页面上拖框；点已有高亮可删除。
- 搜索：跨两门课搜标题/概念/公式，热统结果默认跳教材页码。
- 目录：按文档列出全部章节，点击跳页。
- 翻页：右侧页面滚轮滚到页底/页顶后继续滚动即可翻页；也可点两侧箭头，底部显示页码和操作提示。
- 专注模式：隐藏左侧提纲，全屏看图。
- 导出当前页 PNG、备份/恢复学习数据（进度、书签、笔记、高亮、布局）。
- 拓展页：量子力学提纲顶部/侧栏可进「动量空间四题题解」「氢原子电子云」与「代码版」。
- 汇报材料：发布\氢原子电子云.pdf（5 页左图右码）、发布\氢原子电子云.pptx（10 页公式版，含备注）。

快捷键：
  ← / →        上一页 / 下一页
  Ctrl+1 / 2   切换量子力学 / 热统
  [ / ]        上一份 / 下一份文档
  G            跳到指定页
  + / - / 0    放大 / 缩小 / 适宽
  B            收藏当前页
  H            框选高亮
  N            打开笔记
  T            章节目录
  F            专注模式
  / 或 Ctrl+K  全局搜索
  Esc          关闭面板 / 退出高亮

维护：
  构建\自检.py             检查页面图、manifest、提纲链接、搜索索引
  构建\生成搜索索引.py     修改提纲后重新生成搜索索引
  构建\生成热统教材链接.py 重新生成教材/讲义双链接与 manifest
  页面图统一为 WebP，合计约 154 MB。

注意：
- 程序必须留在普通目录，不要放回 F:\workspace（低完整性，Edge 会白窗）。
- 换电脑时把整个「物理复习提纲合集」一起拷贝；桌面快捷方式需要重新创建。
- 阅读器不联网、不占端口，只依赖系统里的 Edge。
