量子力学的诞生 课件 1-1

原书：无对应节（课件补讲，相关背景见中译本前言） · 课件 1-1，p014–p039

物理图像

19 世纪末，经典物理在三处碰壁：黑体辐射的能量分布（紫外灾难）、光电效应的截止频率与遏止电压、氢原子光谱的分立谱线。三条裂缝分别逼出三个全新的观念 —— 能量量子化、光量子、定态与能级跃迁。量子力学就是在这三条裂缝里诞生的。

课件的叙事顺序是：基尔霍夫 → 维恩 → 瑞利/金斯 → 普朗克（1900）；赫兹/莱纳德 → 爱因斯坦（1905）；巴耳末/里德伯 → 玻尔（1913）。

推导脉络

① 黑体辐射（p015–p021）

  1. 基尔霍夫：黑体吸收并发射一切波长，无反射无透射；热平衡时黑体辐射的谱只由温度决定，与材料、形状无关。
  2. 维恩：由实验得位移律 λmaxT = b，并拟合出 Mλ = Aλ−5e−B/λT —— 短波符合，长波失效。
  3. 瑞利–金斯：按经典电磁理论数出模式数密度（两个横向自由度各 ½kBT），得 Mλ = (2πc/λ⁴)kBT —— 长波符合，短波发散，即紫外灾难。
  4. 普朗克：假设谐振子的能量只能取 0, hν, 2hν, ⋯，交换只能以最小单位 hν 进行。单模平均能量变为 ⟨E⟩ = hν/(ehν/kBT − 1) 从而 Mν = (2πν²/c²)·hν/(ehν/kBT − 1) 低 ν 退化为瑞利–金斯，高 ν 退化为维恩 —— 一条公式统一两极限。

② 光电效应（p022–p027）

  1. 三大反常：存在截止频率；最大动能随 ν 线性增大；光强只决定饱和电流，不影响遏止电压。
  2. 爱因斯坦光量子：Ek,max = hν − W₀ = h(ν − ν₀)。
  3. 遏止电压满足 eUs = hν − W₀，即 Us = (h/e)ν − W₀/e —— 斜率 h/e 与金属无关，是光量子说的判据。

③ 氢光谱与玻尔模型（p028–p037）

  1. 巴耳末系 λ = B·n²/(n² − 4)（n = 3, 4, 5, ⋯）；里德伯公式 1/λ = R(1/n₁² − 1/n₂²)，n₂ > n₁。
  2. 玻尔三假设：定态（轨道上运动不辐射）；角动量量子化 L = nħ；跃迁 hν = Ei − Ef。
  3. 由此得 En = −13.6 eV/n²，谱线系：莱曼 n₁=1、巴耳末 n₁=2、帕邢 n₁=3。

关键结论

普朗克 E = hν = ħω，黑体谱 Mν = (2πν²/c²)·hν/(ehν/kBT−1)。

爱因斯坦 Ek,max = hν − W₀；Us = (h/e)ν − W₀/e，斜率 h/e 对所有金属相同。

玻尔 L = nħ，En = −13.6 eV/n²，hν = Ei − Ef。

共同启示：能量与状态在微观尺度上是分立的；经典物理在微观世界失效。

易错点 课件反复强调

  • 光强 ↔ 频率分工：光强决定光子数（→ 饱和电流），频率决定单个光子能量（→ 能否打出电子、Ek,max）。别把两者混为一谈。
  • 遏止电压不随光强改变 —— 这是经典波动说最致命的反例（课件 p023 红字、p025 专页）。
  • 普朗克公式的两个极限：低 ν → 瑞利–金斯，高 ν → 维恩。这是必会的小题。
  • 玻尔模型只对氢和类氢离子成功，不能解释多电子原子、谱线强度与精细结构；不要把它当成普遍理论。
  • 本套课件到玻尔模型为止，没有康普顿散射、德布罗意波、波粒二象性 —— 这几块属于后续内容，别在这张卡片里找。
  • 谱线系别记反：莱曼系落 n=1（紫外），巴耳末 n=2（可见），帕邢 n=3（红外）。
专题 2

概率论初步 课件 1-2

✓
▼
原书 §1.3，pp.4–8 · 课件 1-2（p01–p26）

物理图像

伽尔顿板：单个小球落点不可预测，大量小球却给出稳定的钟形分布。量子力学的概率是内禀的，但计算工具与经典概率论完全一样：先学会分布、期望、方差、中位数、最可几值，才能读懂 |Ψ|²。

课件的路线是：离散分布（钉板）→ 累积分布（CDF）→ 连续极限（概率密度）→ 特征数 → 中心极限定理 → 例题。

推导脉络
  1. 离散分布：n 层钉板有 n+1 个槽，P(j) = N(j)/N（N→∞ 的频率稳定值），Σj=0nP(j) = 1。
  2. 累积分布：F(j) = Σi≤jP(i)，F(0)=0、F(n+1)=1；P(j) = F(j+1) − F(j)。
  3. 二项分布：P(j) = C(n,j)(1/2)n，平均值 ⟨j⟩ = n/2，标准差 σ = √n/2。
  4. 特征数：众数 jmode = arg max P(j)；中位数 jmed = min{j | F(j) ≥ 1/2}；平均值 ⟨j⟩ = ΣjP(j)。
  5. 方差：σ² = ⟨(j−⟨j⟩)²⟩ = ⟨j²⟩ − ⟨j⟩²；σ 是分布宽度，约 68% 落在 ⟨j⟩ ± σ。
  6. 连续极限：单点概率为零，改用密度 P(x∈[x,x+dx]) = ρ(x)dx，ρ = dF/dx，P(a≤x≤b) = ∫abρdx，⟨x⟩ = ∫xρdx。
  7. 中心极限定理：n→∞ 时二项分布趋于正态 ρ(x) = (1/σ√(2π))e−(x−μ)²/2σ²。

关键结论

归一化：ΣP(j)=1，∫ρ(x)dx=1。

期望与方差：⟨x⟩ = ∫xρdx，σ² = ⟨x²⟩ − ⟨x⟩²。

PDF 与 CDF：ρ(x) 是密度（可大于 1），F(x) 是累计概率（0→1），ρ = dF/dx。课件黄底

课件例题（p23–p25）：自由落体从高 h 处随机时刻释放，落点密度 ρ(x) = 1/(2√(hx))（0≤x≤h）；验证 ∫ρdx = 1，⟨x⟩ = h/3。

易错点

  • 平均值 ≠ 最可几值：二项分布 n=10 时峰值 j=5、平均值 5.00，相等只是对称巧合；一般分布不相等。
  • 连续情形「恰好落在某点」概率为零，只能问区间；把 ρ(x) 当概率是常见错误。
  • σ 是标准差（分布宽度），不是平均误差；方差的展开式 ⟨x²⟩−⟨x⟩² 与定义式等价，但前者好算。
  • 课件数值小瑕疵：二项分布平均值 p015 写 5.00、p012 图注 5.051，按 5 处理即可。
  • 本讲没有 δ 函数；δ 函数在 §2.5（课件 3-5）才出现，不要提前混用。

薛定谔方程

✓
▼
原书 §1.1，p.1 · 课件 2-1（p01–p07）

物理图像

量子力学的「牛顿第二定律」就是薛定谔方程：给定初始波函数 Ψ(x,0)，方程就决定了此后所有时刻的 Ψ(x,t)，正像牛顿定律决定 x(t) 一样。区别在于，方程的解不再是粒子的位置，而是一个复的波函数。

它是基本假设，不能从经典力学「推导」出来；课件用三种方程并排对比，正是为了说明这一点（见推导脉络）。

推导脉络

① 三个方程的对照（课件 2-1 p06）

  1. 牛顿第二定律：m ∂²x/∂t² = −∂V/∂x —— 常微分方程，解 x(t) 是实数。
  2. 经典波动方程：∂²y/∂t² = v² ∂²y/∂x² —— 时间、空间都二阶，解（位移/场强）是实数。
  3. 薛定谔方程：时间一阶、空间二阶，并且带 i，所以解是复数 —— 这是它与经典方程最本质的区别。

② 一维含时薛定谔方程

iħ ∂Ψ/∂t = −(ħ²/2m) ∂²Ψ/∂x² + V(x,t)Ψ

其中 ħ = h/2π = 1.054572×10⁻³⁴ J·s；V(x,t) 为势能。

③ 两种等价表述（课件 2-1 p07）

  1. 波动力学（薛定谔）：以波函数 Ψ 为基本对象，演化由含时薛定谔方程给出。
  2. 矩阵力学（海森堡）：以算符为基本对象，演化由 dÂ/dt = (1/iħ)[Â, Ĥ] + ∂Â/∂t 给出（第三章会系统学）。
完整推导 · 25 步：从德布罗意波到薛定谔方程
目标：把自由粒子的德布罗意关系翻译成微分方程，再推广到有势场的情形。 约定：一维、非相对论、\(m\) 为粒子质量，\(\hbar=h/2\pi\)，\(\Psi\) 为波函数。 每步都给出「为什么可以这样做」；最后单独说明哪些是推导、哪些是基本假设。
  1. 固定物理情境：一维自由粒子

    考虑一个质量为 \(m\) 的粒子，在一维空间运动，暂时没有势场（\(V=0\)），速度远小于光速，用非相对论能量。

    实验上，这种粒子的波动性由德布罗意关系给出：

    \[ E=\hbar\omega,\qquad p=\hbar k. \]

    这里 \(E\) 是能量，\(p\) 是动量，\(\omega\) 是角频率，\(k\) 是波数；\(\hbar=h/2\pi\) 把「频率/波长」和「能量/动量」联系起来。

    依据：德布罗意假设（教材 §1.1 之前的历史线索，课件 2-1）。适用条件：自由粒子、非相对论；\(E=p^2/2m\)。

  2. 写出自由粒子的平面波

    满足上述 \(E,p\) 的最简单的波，是沿 \(+x\) 方向传播的平面波：

    \[ \Psi(x,t)=A\,e^{i(kx-\omega t)}. \]

    \(A\) 是复振幅。这里必须允许 \(\Psi\) 取复值：相位 \(kx-\omega t\) 要同时编码 \(p=\hbar k\) 和 \(E=\hbar\omega\)，实函数只有「振幅 + 符号」，无法独立承载这两个相位。

    为什么是复的：复指数把「空间周期 \(2\pi/k\)」和「时间周期 \(2\pi/\omega\)」放进同一个相位里；后面求导会分别把 \(k\)、\(\omega\) 提出来。

  3. 对时间求导：把 \(\omega\) 提出来

    对 \(t\) 求偏导：

    \[ \frac{\partial\Psi}{\partial t}=-i\omega\,\Psi. \]

    两边乘以 \(i\hbar\)：

    \[ i\hbar\frac{\partial\Psi}{\partial t}=i\hbar(-i\omega)\Psi=\hbar\omega\,\Psi. \]

    用德布罗意关系 \(\hbar\omega=E\)，得到

    \[ i\hbar\frac{\partial\Psi}{\partial t}=E\,\Psi. \]

    依据：\(\hbar\omega=E\)。含义：\(i\hbar\partial_t\) 作用在波函数上，等于「能量乘以波函数」——这就是能量算符的雏形。

  4. 对空间求一阶导：把 \(k\) 提出来

    对 \(x\) 求偏导：

    \[ \frac{\partial\Psi}{\partial x}=ik\,\Psi. \]

    两边乘以 \(-i\hbar\)：

    \[ -i\hbar\frac{\partial\Psi}{\partial x}=-i\hbar(ik)\Psi=\hbar k\,\Psi=p\,\Psi. \]

    所以 \(p\) 对应微分算符

    \[ \hat p=-i\hbar\frac{\partial}{\partial x}. \]

    依据：\(p=\hbar k\)。含义：动量不是「数」，而是作用在波函数上的动量算符；\(-i\hbar\partial_x\) 才能让平面波本征值为实数 \(p\)。

  5. 对空间求二阶导：把 \(k^2\) 提出来

    再求一次导：

    \[ \frac{\partial^2\Psi}{\partial x^2}=(ik)^2\Psi=-k^2\Psi. \]

    两边乘以 \(-\hbar^2/2m\)：

    \[ -\frac{\hbar^2}{2m}\frac{\partial^2\Psi}{\partial x^2} =-\frac{\hbar^2}{2m}(-k^2)\Psi =\frac{\hbar^2k^2}{2m}\Psi. \]

    为什么用二阶导：非相对论动能 \(T=p^2/2m\) 含 \(p^2\)，而 \(p^2\) 对应 \((-i\hbar\partial_x)^2=-\hbar^2\partial_x^2\)。一阶导只能给 \(p\)，给不了 \(p^2\)。

  6. 用自由粒子色散关系把 \(E\) 和 \(k\) 连起来

    自由粒子的能量只有动能：

    \[ E=\frac{p^2}{2m}=\frac{\hbar^2k^2}{2m}. \]

    于是角频率

    \[ \omega=\frac{E}{\hbar}=\frac{\hbar k^2}{2m}. \]

    检查：\(k\) 越大，\(\omega\) 越大；\(m\to\infty\) 时 \(\omega\to0\)，回到经典「重粒子几乎不动」的极限。这个关系叫色散关系。

  7. 拼出自由粒子的薛定谔方程

    把第 3 步的 \(E\Psi\) 和第 5 步的 \(\frac{\hbar^2k^2}{2m}\Psi\) 用第 6 步的 \(E=\frac{\hbar^2k^2}{2m}\) 等同起来：

    \[ i\hbar\frac{\partial\Psi}{\partial t} =E\Psi =\frac{\hbar^2k^2}{2m}\Psi =-\frac{\hbar^2}{2m}\frac{\partial^2\Psi}{\partial x^2}. \]

    即

    \[ \boxed{\,i\hbar\frac{\partial\Psi}{\partial t} =-\frac{\hbar^2}{2m}\frac{\partial^2\Psi}{\partial x^2}\,}. \]

    适用范围：只对自由粒子、平面波推导出来。不是：对任意势场的证明；第 10 步才把它推广为假设。

  8. 验证：平面波确实满足方程

    把 \(\Psi=Ae^{i(kx-\omega t)}\) 代回第 7 步的方程：左边 \(i\hbar(-i\omega)\Psi=\hbar\omega\Psi\)，右边 \(-\frac{\hbar^2}{2m}(-k^2)\Psi=\frac{\hbar^2k^2}{2m}\Psi\)。

    两边相等，当且仅当

    \[ \hbar\omega=\frac{\hbar^2k^2}{2m}, \]

    这正是自由粒子的色散关系。说明方程和德布罗意关系是自洽的。

    检查：方程对 \(\Psi\) 是线性的；\(A\) 任意，所以解的叠加仍是解。

  9. 叠加原理：为什么方程必须是线性的

    若 \(\Psi_1,\Psi_2\) 都是解，则对任意复系数 \(c_1,c_2\)，

    \[ \Psi=c_1\Psi_1+c_2\Psi_2 \]

    仍是解。因为方程对 \(\Psi\) 及其导数都是一次的，没有 \(\Psi^2\)、\(\Psi\Psi^*\) 这类项。

    物理上，这意味着「两条可能路径的概率幅可以相加」，才会出现干涉；如果方程是非线性的，叠加原理和量子干涉都不成立。

    知识点：叠加原理；它是量子力学的公设之一，不是从方程「推」出来的，但方程必须线性才能容纳它。

  10. 先加一个常数势 \(V_0\)

    若空间各点都有相同的势能 \(V_0\)，总能量变成

    \[ E=\frac{p^2}{2m}+V_0. \]

    平面波的频率相应变为

    \[ \omega=\frac{1}{\hbar}\left(\frac{\hbar^2k^2}{2m}+V_0\right). \]

    模仿第 7 步，得到

    \[ i\hbar\frac{\partial\Psi}{\partial t} =\left(-\frac{\hbar^2}{2m}\frac{\partial^2}{\partial x^2}+V_0\right)\Psi. \]

    检查：\(V_0\) 只把能量零点平移，不改变概率分布；物理上不可观测绝对势能零点。

  11. 把常数势换成 \(V(x,t)\)：从「推导」变成「假设」

    当势能随位置/时间变化时，平面波不再是精确解（\(k\) 不再恒定），上面的推导链条断了。量子力学的基本做法是：把 \(V_0\) 直接替换成 \(V(x,t)\)，并要求方程局部成立：

    \[ \boxed{\,i\hbar\frac{\partial\Psi}{\partial t} =\left[-\frac{\hbar^2}{2m}\frac{\partial^2}{\partial x^2}+V(x,t)\right]\Psi\,}. \]

    这就是一维含时薛定谔方程。它是基本假设，不能从经典力学严格证明；前面的平面波推导只是「猜出它的历史线索」。

    依据：教材式 (1.1)、课件 2-1 p06。适用：非相对论、单粒子、势场给定；不适用于相对论/强场/粒子产生湮灭。

  12. 为什么时间是一阶，空间是二阶？

    时间一阶意味着：只要知道初始时刻的 \(\Psi(x,0)\)，方程就唯一决定之后所有时刻的 \(\Psi(x,t)\)，不需要 \(\partial_t\Psi(x,0)\)。这与「波函数完全描述状态」的假设一致。

    空间二阶来自动能 \(p^2/2m\)：\(p^2\) 对应二阶空间导数。经典波动方程时间也是二阶，需要「初始位移 + 初始速度」两个初值；薛定谔方程只需要一个初值。

    推论：概率流守恒（第 16 步）依赖「时间一阶 + 方程线性」；如果时间二阶，概率密度一般不再守恒。

  13. 为什么必须出现 \(i\)？

    若方程是实系数的，实波函数的解只能做「振动」，无法让相位 \(e^{i(kx-\omega t)}\) 独立传播；而相位差正是干涉和动量/能量编码的来源。

    更技术地说，\(i\) 让演化算符 \(e^{-i\hat Ht/\hbar}\) 成为酉算符，保证概率守恒；去掉 \(i\) 会得到指数增长/衰减的解，概率不守恒。

    知识点：复波函数、相位、酉演化；这里只做动机说明，严格证明在第三章形式理论。

  14. 算符对应：把经典量换成微分算符

    从第 3、4、5 步可以总结出替换规则：

    \[ E\;\longrightarrow\;i\hbar\frac{\partial}{\partial t},\qquad p\;\longrightarrow\;-i\hbar\frac{\partial}{\partial x},\qquad p^2\;\longrightarrow\;-\hbar^2\frac{\partial^2}{\partial x^2}. \]

    于是经典能量关系 \(E=p^2/2m+V\) 变成作用在 \(\Psi\) 上的算符方程，这就是薛定谔方程。

    注意：这是「对应规则」，不是严格推导；算符的顺序、厄密性在第三章讨论（算符）。

  15. 推广到三维

    把 \(p_x\to-\mathrm{i}\hbar\partial_x\) 换成矢量动量算符

    \[ \hat{\mathbf p}=-\mathrm{i}\hbar\nabla, \]

    动能算符变成

    \[ \hat T=\frac{\hat{\mathbf p}\cdot\hat{\mathbf p}}{2m} =-\frac{\hbar^2}{2m}\nabla^2. \]

    三维含时薛定谔方程为

    \[ i\hbar\frac{\partial\Psi}{\partial t} =\left[-\frac{\hbar^2}{2m}\nabla^2+V(\mathbf r,t)\right]\Psi. \]

    检查：一维时 \(\nabla^2=\partial_x^2\)，回到第 11 步；三维动能仍是非负算符。

  16. 波函数的概率诠释与归一化

    薛定谔方程只给出 \(\Psi\) 的演化，不直接说明 \(\Psi\) 是什么。玻恩的统计诠释规定：

    \[ \rho(x,t)=|\Psi(x,t)|^2 \]

    是概率密度，即在 \([x,x+\mathrm{d}x]\) 内发现粒子的概率为 \(\rho\,\mathrm{d}x\)。因此必须满足

    \[ \int_{-\infty}^{+\infty}|\Psi(x,t)|^2\,\mathrm{d}x=1. \]

    这就是归一化条件；只有平方可积的波函数才能这样归一。

    知识点：概率密度、玻恩规则；详见 §1.2、§1.4。

  17. 概率守恒：从方程推出连续性方程

    令 \(\rho=\Psi^*\Psi\)，对时间求导：

    \[ \partial_t\rho=(\partial_t\Psi^*)\Psi+\Psi^*(\partial_t\Psi). \]

    由薛定谔方程及其复共轭：

    \[ \partial_t\Psi=\frac{i\hbar}{2m}\partial_x^2\Psi-\frac{i}{\hbar}V\Psi,\qquad \partial_t\Psi^*=-\frac{i\hbar}{2m}\partial_x^2\Psi^*+\frac{i}{\hbar}V\Psi^*. \]

    代入后势能项相消：

    \[ \partial_t\rho=\frac{i\hbar}{2m}\left(\Psi^*\partial_x^2\Psi-\Psi\partial_x^2\Psi^*\right) =-\partial_x j, \]

    其中

    \[ j=\frac{\hbar}{2mi}\left(\Psi^*\partial_x\Psi-\Psi\partial_x\Psi^*\right). \]

    于是

    \[ \partial_t\rho+\partial_x j=0. \]

    这就是连续性方程：概率不会凭空产生或消失，只会流动。

    检查：对全空间积分，若 \(j\) 在无穷远衰减，则 \(\frac{d}{dt}\int\rho\,dx=0\)，归一化不随时间改变。

  18. 边界条件与正则性

    解方程还需要边界条件。物理上要求：

    • \(\Psi\) 在全空间连续（概率密度不能突变）；
    • 在势能有限的地方，\(\partial_x\Psi\) 也连续（动能有限）；
    • \(\Psi\) 平方可积，无穷远处趋于 0；
    • 无限深势阱的壁外 \(\Psi=0\)。

    知识点：边界条件；这些条件不是方程本身，而是「波函数代表物理态」的附加要求。§2.2、§2.5 会反复用。

  19. 势能与时间无关时：分离出定态

    若 \(V=V(x)\)，设

    \[ \Psi(x,t)=\psi(x)\,e^{-\mathrm{i}Et/\hbar}. \]

    代入含时方程：左边 \(i\hbar(-\mathrm{i}E/\hbar)\Psi=E\Psi\)，右边 \(e^{-\mathrm{i}Et/\hbar}[-\frac{\hbar^2}{2m}\psi''+V\psi]\)。约去时间因子：

    \[ -\frac{\hbar^2}{2m}\frac{\mathrm{d}^2\psi}{\mathrm{d}x^2}+V(x)\psi=E\psi. \]

    这就是定态薛定谔方程；\(E\) 是能量本征值。

    知识点：定态；详见 §2.1。注意分离变量要求 \(V\) 不显含 \(t\)。

  20. 自由粒子极限：回到平面波

    令 \(V=0\)，定态方程变为

    \[ -\frac{\hbar^2}{2m}\psi''=E\psi, \]

    解为 \(\psi=e^{\pm ikx}\)，\(E=\hbar^2k^2/2m\)。加上时间因子就是第 2 步的平面波。

    但平面波不平方可积，不能直接归一化；实际自由粒子要用波包（不同 \(k\) 的叠加）来描述。

    检查：\(k\) 任意连续，所以自由粒子能谱连续；束缚态才出现离散能级。

  21. 经典极限：\(\hbar\to0\) 时回到牛顿力学

    当作用量远大于 \(\hbar\)、德布罗意波长远小于体系尺度时，波包的中心的运动满足经典方程；相位 \(S/\hbar\) 的梯度给出动量，哈密顿–雅可比方程出现。

    这不是说「量子力学变成经典力学」，而是说经典力学是量子力学在 \(\hbar\to0\) 的近似；干涉/隧穿等效应在此极限下指数小。

    知识点：经典极限；严格讨论见后续章节/教材补充。

  22. 量纲检查

    逐项检查方程 \(i\hbar\partial_t\Psi=[-\frac{\hbar^2}{2m}\partial_x^2+V]\Psi\) 的量纲（以焦耳 J 为单位）：

    • \([\hbar\partial_t]=(\mathrm{J\cdot s})(\mathrm{s^{-1}})=\mathrm{J}\)；
    • \([\frac{\hbar^2}{2m}\partial_x^2]=\frac{(\mathrm{J\cdot s})^2}{\mathrm{kg}}\cdot\mathrm{m^{-2}} =\frac{\mathrm{J^2\cdot s^2}}{\mathrm{kg\cdot m^2}}=\mathrm{J}\)；
    • \([V]=\mathrm{J}\)。

    三项同量纲，方程成立。若把 \(\hbar\) 写成 \(h\)，会多出 \(2\pi\) 因子，量纲仍对但数值错。

    检查：这是最快发现「漏了 \(\hbar\)」或「\(\partial_x^2\) 写成 \(\partial_x\)」的方法。

  23. 平面波不能直接归一化：需要波包

    \(\int_{-\infty}^{\infty}|Ae^{ikx}|^2dx=|A|^2\int dx=\infty\)，平面波不属于平方可积空间。物理上的自由粒子用波包

    \[ \Psi(x,0)=\int_{-\infty}^{\infty}\tilde\Psi(k)e^{ikx}\,\frac{\mathrm{d}k}{\sqrt{2\pi}} \]

    描述；不同 \(k\) 叠加后可以在有限区域归一化。

    知识点：归一化、希尔伯特空间；严格处理见 §2.4、§3.1、§3.3。

  24. 哪些是推导，哪些是假设？

    推导得到：自由粒子的平面波满足 \(i\hbar\partial_t\Psi=-\frac{\hbar^2}{2m}\partial_x^2\Psi\)；这是德布罗意关系 + 非相对论色散的必然结果。

    作为假设：把自由粒子方程推广到任意 \(V(x,t)\)；玻恩概率诠释；波函数完全描述状态；测量公设。

    所以「薛定谔方程不能从经典力学证明」这句话是对的；但「自由粒子情形可以从德布罗意关系猜出来」也是对的，两者不矛盾。

    易错：不要把「历史线索」当成「严格证明」；也不要把「基本假设」当成「凭空捏造」。

  25. 一页总结：方程、条件、常见错误

    方程：

    \[ i\hbar\frac{\partial\Psi}{\partial t} =\left[-\frac{\hbar^2}{2m}\nabla^2+V\right]\Psi. \]

    条件：非相对论、单粒子、势场给定；\(\Psi\) 平方可积、满足边界条件。

    常见错误：① 把 \(\hbar\) 写成 \(h\)；② 时间也写成二阶；③ 把 \(V\) 当力；④ 以为平面波可以直接归一；⑤ 以为方程能由经典力学严格推出。

    自检：能否不看上面，独立写出方程、说出时间一阶/空间二阶的理由、并推出连续性方程？

关键结论

含时薛定谔方程（一维）： iħ ∂Ψ/∂t = −(ħ²/2m) ∂²Ψ/∂x² + VΨ（式 1.1，p.1）。

解是复数波函数 Ψ(x,t)，它本身没有直接的可观测意义，其物理含义由 §1.2 的统计诠释给出。

地位：量子力学的基本假设，逻辑上相当于经典力学中的牛顿第二定律。课件强调

易错点

  • 薛定谔方程不能由经典物理推出，它是假设；「从德布罗意波猜出来」只是历史线索，不是证明。
  • 方程里是 时间一阶、空间二阶：所以初始条件只需 Ψ(x,0)，不需要 ∂Ψ/∂t 的初值（与经典波动方程不同）。
  • V 是势能，不是力；力对应 −∂V/∂x，只在物理图像里用于类比。
  • 波函数是复数，但任何可观测量的期望值必须是实数 —— 这要求算符是厄密的（§3.2）。
  • 课件 2-1 的红框方程是一维形式；三维形式把 ∂²/∂x² 换成 ∇²（第八章才系统用）。
§1.2

波函数的统计诠释

✓
▼
原书 §1.2，pp.1–3 · 课件 2-2（p01–p08）

物理图像

薛定谔方程给出 Ψ，可「Ψ 到底描述什么」是量子力学最核心的诠释问题。玻恩的答案是：|Ψ(x,t)|² 是概率密度 —— Ψ 本身不是物质波，而是概率幅。

因此单次测量不可预言，只能预言「大量同样制备的系统」的统计分布；测量之后，波函数坍缩到测量结果对应的本征态。

要点梳理

  • 概率密度：在 x 附近 dx 内发现粒子的概率为 |Ψ(x,t)|² dx。
  • 区间概率：P(a ≤ x ≤ b) = ∫ab |Ψ(x,t)|² dx。
  • 归一化：∫−∞+∞ |Ψ|² dx = 1（详见 §1.4）。
  • 波包：Ψ = exp(−x²/2) 型波包，|Ψ|² 的峰位即最可几位置；波包越窄，位置越确定，动量越弥散（不确定原理的伏笔）。
  • 与经典对照：经典轨道 x(t) 失效，代之以「概率云」Ψ*Ψ；经典波（位移/场强）与量子波（概率幅）物理含义不同。

关键结论

统计诠释：ρ(x,t) = |Ψ(x,t)|² 是概率密度；Ψ 是概率幅，不是可观测的物理量。

单次测量结果不可预言；对大量全同系统，结果的分布由 |Ψ|² 给出；测量后波函数坍缩。

诠释之争：玻恩/玻尔（正统、概率、互补原理）vs 爱因斯坦（「上帝不掷骰子」，隐变量）；测量问题、隐变量、多世界、退相干至今仍是开放问题。课件展开

易错点

  • Ψ 本身不是概率，|Ψ|² 才是；Ψ 可以有节点（为零），节点处发现粒子的概率为零。
  • 概率密度有量纲（1/长度），|Ψ|²dx 才是无量纲概率。
  • 波函数的整体相位 eiθ 不影响 |Ψ|²，但相对相位会影响干涉 —— 这是量子力学与经典概率最不同的地方。
  • 「坍缩」不是薛定谔方程演化出来的，是诠释里额外加的测量假设；课件 2-2 明确把它列为未解困惑之一。
  • 概率诠释只适用于归一化（平方可积）的波函数；平面波 eikx 不能直接归一（§2.4、§3.3 处理）。
§1.3

概率论

✓
▼
原书 §1.3，pp.4–8 · 课件 1-2（p01–p26）

物理图像

伽尔顿板：单个小球落点不可预测，大量小球却呈现稳定的钟形分布。量子力学的概率不是「知识不足」，而是内禀的；但计算工具与经典概率论完全一样 —— 分布、期望、方差、中位数、最可几值。

这一节把「离散的概率 P(j)」过渡到「连续的概率密度 ρ(x)」，为 |Ψ|² 的运算做准备。

推导脉络
  1. 离散分布：P(j) = N(j)/N（N → ∞ 时的频率稳定值），Σj P(j) = 1。
  2. 累积分布（CDF）：F(j) = Σi≤j P(i)，F(0)=0、F(n+1)=1；P(j) = F(j+1) − F(j)。
  3. 连续极限：单点概率为零，改用密度 P(x ∈ [x, x+dx]) = ρ(x) dx；ρ = dF/dx，P(a ≤ x ≤ b) = ∫ab ρ dx。
  4. 期望值：⟨j⟩ = Σj jP(j)；⟨f(j)⟩ = Σj f(j)P(j)；连续情形 ⟨x⟩ = ∫ xρ(x) dx。
  5. 方差：σ² = ⟨(x−⟨x⟩)²⟩ = ⟨x²⟩ − ⟨x⟩²，σ = √σ² 是分布的宽度。
  6. 三个「中心」：最可几值（众数，P 最大处）、中位数（F ≥ 1/2 的最小 x）、平均值 ⟨x⟩。对称分布三者相等，一般不等。
  7. 中心极限定理：n → ∞ 时二项分布趋于正态 ρ(x) = (1/σ√(2π)) e−(x−μ)²/2σ²（书 §1.3 的推导）。

关键结论

归一化：ΣP(j) = 1，∫ρ(x) dx = 1。

期望与方差：⟨x⟩ = ∫xρ dx，σ² = ⟨x²⟩ − ⟨x⟩²。

离散 ↔ 连续：P(j) → ρ(x)dx，Σ → ∫。

课件例题（1-2 p23–p25）：自由落体从高 h 处随机时刻释放，落点密度 ρ(x) = 1/(2√(hx))（0 ≤ x ≤ h），可验证 ∫ρ dx = 1，⟨x⟩ = h/3。课件例题

易错点

  • PDF 与 CDF 别混：ρ(x) 是密度（可大于 1），F(x) 是累计概率（0→1）；ρ = dF/dx。
  • 平均值 ≠ 最可几值：二项分布 n=10 时峰值是 j=5（P=0.243），平均值 5.00，看起来相等只是对称性巧合；一般不对称分布不相等。
  • 连续情形下问「恰好落在某点」的概率是 0，只能问区间概率。
  • 方差的展开式 ⟨x²⟩ − ⟨x⟩² 与定义式 ⟨(x−⟨x⟩)²⟩ 等价，但前者好算 —— 考试常用。
  • 课件里二项分布的平均值有一处数值不一致（p015 写 5.00，p012 图注 5.051），按 5 处理即可，不必纠结。
§1.4

归一化

✓
▼
原书 §1.4，pp.8–9 · 课件 2-3（p01–p08）

物理图像

薛定谔方程是线性的：若 Ψ 是解，CΨ 也是解。可是概率必须总和为 1，波函数不能任意乘常数 —— 归一化就是把这个常数定下来。它不改变任何物理结论，只把「同一个态」的表示规范化。

推导脉络
  1. 为什么必须归一化：概率诠释要求 ∫|Ψ|²dx = 1；方程线性使 Ψ 的常数因子不定，必须用一个条件把它固定。
  2. 三条作用：定出未定的乘法常数；排除平庸解 Ψ ≡ 0；把「物理可实现的态」限定为方程的平方可积解。
  3. 归一化是否稳定（课件 2-3 p05–p06 的证明）：令 N(t) = ∫ |Ψ(x,t)|² dx 把含时薛定谔方程及其共轭代入 dN/dt，分部积分并用边界项为零，得 dN/dt = 0。所以初始归一 → 永远归一。

关键结论

归一化条件：∫−∞+∞ |Ψ(x,t)|² dx = 1（式 1.20 附近，p.8）。

归一化在时间演化下保持（dN/dt = 0）—— 这保证理论自洽，也是「概率守恒」的来源。

物理态 ↔ 平方可积的归一化解；平面波不可归一，只能作为「理想化工具」处理（见 §2.4、§3.3）。

易错点

  • 归一化因子求出后，整段计算都要带着它；只对部分区间积分不等于总概率 1。
  • 未归一化时，期望值公式要写成比值 ⟨x⟩ = ∫x|Ψ|²dx / ∫|Ψ|²dx，否则数值无意义。
  • 归一化不改变相对概率、不改变能量本征值；两种归一化只差一个常数相位/因子。
  • 课件 2-3 的例题（p08）：Ψ(x,0) 是分段线性函数，先定 A，再求最可几位置、区间概率与 ⟨x⟩ —— 这类题是考试标配，步骤不要跳。
§1.5

动量与期望值

✓
▼
原书 §1.5，pp.10–11 · 课件 2-4（p01–p08）

物理图像

经典里「平均值」是随机变量乘概率密度积分；量子里「位置」仍是 x，但「动量」不再是数，而是一个算符 p̂ = −iħ ∂/∂x。期望值公式于是变成「波函数夹着算符」的三明治结构。

由此可以证明 Ehrenfest 定理：量子期望值满足与经典牛顿定律形式相同的方程 —— 量子力学在「平均」意义上恢复经典。

推导脉络
  1. 位置期望：⟨x⟩ = ∫ x |Ψ(x,t)|² dx。
  2. 动量期望：对 ⟨x⟩ 求时间导数，用含时薛定谔方程代入、分部积分并丢弃边界项，得 d⟨x⟩/dt = −(iħ/m)∫ Ψ* ∂Ψ/∂x dx 于是识别出 ⟨p⟩ = ∫ Ψ*(−iħ ∂/∂x)Ψ dx
  3. 一般力学量：⟨Q⟩ = ∫ Ψ* Q̂(x, −iħ∂/∂x) Ψ dx；算符表：x̂ = x，p̂ = −iħ∂ₓ，T̂ = −(ħ²/2m)∂ₓ²，Ĥ = T̂ + V̂。
  4. Ehrenfest 定理：d⟨x⟩/dt = ⟨p⟩/m，m d²⟨x⟩/dt² = ⟨−∂V/∂x⟩ = ⟨F⟩。

关键结论

动量算符：p̂ = (ħ/i) ∂/∂x = −iħ ∂/∂x（式 1.30，p.10）。

期望值公式：⟨Q⟩ = ∫ Ψ* Q̂ Ψ dx（三明治：Ψ* 夹算符夹 Ψ）。

Ehrenfest 定理：d⟨x⟩/dt = ⟨p⟩/m，m d²⟨x⟩/dt² = ⟨F⟩（p.11）。课件重点

算符对应：x → x，p → −iħ∂ₓ，T → −(ħ²/2m)∂ₓ²，V → V(x)。

易错点

  • 算符作用在它右边的整个波函数上：p̂(xΨ) = −iħ(Ψ + x∂ₓΨ)，不能只乘 x。
  • ⟨p⟩ 不是 m d⟨x⟩/dt 的定义，而是由 Ehrenfest 定理推出它等于后者；顺序别反。
  • 期望值公式里 Ψ* 与 Ψ 不能写成 |Ψ|² 再乘算符（除非算符与 x 对易）。
  • 厄密算符保证期望值为实数；若算出复数，检查算符是否厄密或积分是否漏了共轭。
  • 课件 2-4 封面公式排版错乱，不要去背它，以正文 ⟨Q⟩ = ∫Ψ*Q̂Ψdx 为准。

不确定原理

✓

经典波也一样：一段很长的波列（波长确定）无法定位；一个短脉冲（位置确定）又由许多波长叠加而成。德布罗意把 p = h/λ 接到粒子上，于是「位置确定」与「动量确定」成了互相排斥的两件事 —— 这就是不确定原理。

它不是仪器精度不够，而是波粒二象性的内禀结果；课件用双缝 + X 射线散射电子的图来说明。

推导脉络（课件版）

课件只给直观论证，严格证明留到 §3.5：

  1. 经典波列：波长确定 ⇒ 位置不确定；孤子/脉冲：位置确定 ⇒ 波长（动量）不确定。
  2. 德布罗意 p = h/λ 把「波长」换成「动量」。
  3. 于是 σxσp ≥ ħ/2（海森堡不确定关系），σ 为标准差。

严格证明（§3.5）：由施瓦茨不等式 + 对易子 [x̂, p̂] = iħ，得 σxσp ≥ ħ/2；取等号的条件是波函数为高斯型 —— 即「最小不确定波包」。

关键结论

不确定关系：σxσp ≥ ħ/2（式 1.41，p.12）。课件红框

标准差（不确定度）：σA = √(⟨A²⟩ − ⟨A⟩²)。

高斯波包（课件 2-5 例题）：Ψ(x,t) = A e−a[(mx²/ħ) + it]，可验证 σxσp = ħ/2 取等号。

物理含义：位置越确定（σx 小），动量越弥散；反之亦然。这就是「量子涨落」的定量表述。

易错点

  • σ 是标准差，不是测量误差，也不是「仪器精度」；它是同一个态反复测量的统计散布。
  • 课件 2-5 封面把不等号写成 ≤，正文是 ≥ —— 以 ≥ 为准（课件笔误）。
  • Δx Δp ≈ h 是量级估算，严格式子是 σxσp ≥ ħ/2，差一个 2π，别写错。
  • 取等号的条件是高斯波包；普通波包乘积大于 ħ/2。
  • 不确定原理不禁止「同时测量」到近似值，只限制两者散布的乘积下界；也不能用它解释「测量扰动」的全部（那是另一种表述）。

§2.1

定态

✓
▼
原书 §2.1，pp.16–19 · 课件 3-1（p01–p14）

物理图像

若势能 V(x) 不显含时间，含时薛定谔方程可以「分离变量」：时间部分给一个纯相位因子，空间部分满足一个不含时的方程。这样解出来的态叫定态。

定态并不「静止」——波函数仍在振荡，但概率密度不随时间变化，能量也完全确定。这是全部一维问题的起点：先解定态方程，再用定态叠加构造任意含时解。

推导脉络
  1. 设 V 不显含 t，令 Ψ(x,t) = ψ(x)φ(t)，代入含时薛定谔方程并除以 ψφ： iħ (1/φ) dφ/dt = −(ħ²/2m)(1/ψ) d²ψ/dx² + V
  2. 左边只含 t、右边只含 x，故两边都等于同一常数 E。
  3. 时间方程 iħ dφ/dt = Eφ 给出 φ(t) = e−iEt/ħ；空间方程就是定态薛定谔方程： −(ħ²/2m) d²ψ/dx² + Vψ = Eψ
  4. 定态的三条性质：① 概率密度 |Ψ|² = |ψ|² 与时间无关，期望值也只需用 ψ 算；② 能量完全确定（σH = 0）；③ 任意解可写成定态的叠加 Ψ(x,t) = Σn cnψn(x)e−iEnt/ħ 系数由初态 cn = ∫ψn*Ψ(x,0)dx 定（正交归一性保证）。

关键结论

定态薛定谔方程：−(ħ²/2m)ψ″ + Vψ = Eψ（式 2.5，p.16）。课件红框

定态：Ψ = ψ(x)e−iEt/ħ，概率密度不随时间变，能量取确定值 E。

一般解：Ψ = Σ cnψne−iEnt/ħ；cn = ⟨ψn|Ψ(0)⟩。叠加态的概率密度会随时间振荡（拍频 |E₂−E₁|/ħ）。

「不同的物理条件只体现在势 V(x) 里」—— 这是本章反复用的思想。课件强调

易错点

  • 定态不是「什么都不动」：波函数有 e−iEt/ħ 相位，|Ψ|² 才不随时间变。
  • 只有 V 不显含 t 才能分离变量；含时势必须解完整的含时方程。
  • 叠加态一般不是定态：两态叠加的 |Ψ|² 含 cos[(E₂−E₁)t/ħ] 交叉项（课件 3-1 例题，式 14）。
  • 能量零点可任取，所以 E 可正可负；只有「相对势垒」才有意义。
  • ψ 是定态方程的解，Ψ 是含时解；求期望值时用哪一个都行，但不要混写。
§2.2

一维无限深方势阱

✓
▼
原书 §2.2，pp.20–25 · 课件 3-2（p01–p12）

物理图像

把粒子关进「无限高」的盒子：0 < x < a 内 V=0，外面 V=∞。盒外波函数必须为零，盒内是自由粒子 —— 但两端钉死在零，于是只有驻波能存在，能量被量子化。

这是最简单的束缚态模型：波函数节点数 = n−1，能级 En ∝ n² 不等间距，基态能量不为零（零点能）。

推导脉络
  1. 分区：盒外 ψ = 0；盒内 ψ″ = −k²ψ，k = √(2mE)/ħ，通解 ψ = A sin kx + B cos kx
  2. 边界条件（ψ 连续）：ψ(0) = 0 ⟹ B = 0；ψ(a) = 0 ⟹ kna = nπ，即 kn = nπ/a（n = 1, 2, 3, …）。
  3. 能级：En = ħ²kn²/2m = n²π²ħ²/(2ma²)。
  4. 归一化：∫0a|A|²sin²(nπx/a)dx = |A|²a/2 = 1，故 A = √(2/a)。
  5. 正交归一：∫ψm*ψndx = δmn（积化和差即可证）。
  6. 任意初态展开：Ψ(x,0) = Σcnψn，cn = ∫ψn*Ψ(x,0)dx；能量期望 ⟨H⟩ = Σ|cn|²En。

关键结论

波函数与能级（式 2.27、2.28，p.20）： ψn = √(2/a) sin(nπx/a)，En = n²π²ħ²/(2ma²)，n = 1, 2, 3, …

正交归一：⟨ψm|ψn⟩ = δmn；完备：任意函数可展开。

图像：ψ1 无节点、偶对称；ψ2 一个节点、奇；ψ3 两个节点、偶；节点数 = n − 1。课件 p04 图

课件例题（p10）：Ψ(x,0) = Ax(a−x)，先由归一化得 A = √(30/a⁵)，再求 cn 与含时解 —— 偶数 n 的系数为零。

易错点

  • n 从 1 开始：n=0 给出 ψ≡0，没有物理意义（归一化失败）。
  • 能级 ∝ n²，不是等间距；间距随 n 增大而变大。
  • 波函数在壁上连续（为零），但导数在壁上不连续 —— 因为 V=∞，这是允许的例外。
  • 「偶/奇」是相对盒中心 a/2 说的，不是相对 x=0；写宇称时注意坐标原点。
  • 展开系数 cn 由初态决定，不要与 ψn 本身混淆；Σ|cn|² = 1 可用来验算。
§2.3

谐振子

✓
▼
原书 §2.3，pp.26–38 · 课件 3-3（p01–p14）

物理图像

任何势能在极小点附近都可以近似成抛物线 V ≈ ½mω²x²，所以谐振子不只是「弹簧」，而是一切束缚体系的通用模型，也是量子场论的基础工具（课件星标）。

它的能级是等间距的 En = (n+½)ħω：有零点能、能级步长恒为 ħω，这些都与无限深阱的 n² 分布形成对照。

推导脉络（代数法）
  1. 哈密顿量 H = p²/2m + ½mω²x²。定义升降算符 a± = (1/√(2mωħ))(∓ip + mωx)
  2. 由 [x, p] = iħ 得 [a−, a+] = 1，并且 a−a+ = H/ħω + ½，　a+a− = H/ħω − ½ 故 H = ħω(a+a− + ½)。
  3. 若 ψ 是能量 E 的定态，则 a+ψ 的能量为 E+ħω、a−ψ 为 E−ħω（「爬梯子」）。
  4. 梯子必须到底：存在 ψ0 使 a−ψ0 = 0，解微分方程得 ψ0 = (mω/πħ)1/4 e−mωx²/2ħ，　E0 = ½ħω
  5. 逐级上升：ψn = (1/√(n!))(a+)nψ0，En = (n+½)ħω；矩阵元 a+ψn = √(n+1)ψn+1，a−ψn = √n ψn−1。
  6. 算符的厄密共轭关系：∫f*(a±g)dx = ∫(a∓f)*g dx；由此可证正交性。

解析法（幂级数、厄密多项式）给出同一组能级，但代数法更干净，也是后续「二次量子化」的雏形。

关键结论

能级：En = (n + ½)ħω，ω = √(k/m)，n = 0, 1, 2, …（等间距，零点能 ½ħω）。

基态：ψ0 = (mω/πħ)1/4e−mωx²/2ħ（高斯型，最小不确定波包）。

升降算符：a± = (1/√(2mωħ))(∓ip + mωx)；[a−,a+]=1，H = ħω(a+a−+½)。

课件例题（p11）：用 x = √(ħ/2mω)(a++a−) 算 ⟨V⟩ = ½mω²⟨x²⟩ = ½ħω(n+½) = ½En —— 与位力定理一致。

易错点

  • 零点能不能丢：E0 = ½ħω ≠ 0，这是不确定原理的直接后果。
  • a−ψ0 = 0 是「梯子到底」的条件，不是「a− 作用在任何态都为零」；对 n ≥ 1，a−ψn = √n ψn−1 ≠ 0。
  • 算符顺序不能交换：a+a− ≠ a−a+，差 1 就是 [a−,a+]=1。
  • ω 由势的曲率给出：ω = √(V″/m)，不要与经典频率混淆单位。
  • 谐振子波函数有奇偶性（ψn 宇称 (−1)n），但这不是所有势都有的性质，只对对称势成立。
§2.4

自由粒子

✓
▼
原书 §2.4，pp.39–44 · 课件 3-4（p01–p10）

物理图像

自由粒子 V=0 的解是平面波 eikx，能量可以取任意正值（连续谱）。但平面波在全空间不可归一 —— 它不是物理态，只能作为「理想化基元」；真正的粒子是这些平面波的叠加（波包）。

波包有两个速度：相位传播的 vp 与包络传播的 vg。量子力学里只有群速度对应经典粒子速度。

推导脉络
  1. 定态方程 −(ħ²/2m)ψ″ = Eψ，k = √(2mE)/ħ，解 ψk(x) = Aeikx + Be−ikx，　E = ħ²k²/2m k>0 右行、k<0 左行；E 任意正数。
  2. 含时解：Ψk(x,t) = Aei(kx−ωt)，ω = ħk²/2m。
  3. 相速度 vp = ω/k = ħk/2m = √(E/2m)；群速度 vg = dω/dk = ħk/m = √(2E/m)。
  4. 与经典对比：经典 v = √(2E/m) = vg；而 vp = vg/2。非相对论自由粒子的相速度不等于粒子速度。
  5. 不可归一的原因：∫|ψ|²dx = |A|²∫dx → ∞。补救：把权重换成 φ(k)，求和变积分 Ψ(x,t) = (1/√(2π))∫φ(k)ei(kx−ωt)dk 反演 φ(k) = (1/√(2π))∫Ψ(x,0)e−ikxdx。
  6. 课件例题（方波包）：Ψ(x,0) = A（|x|<a）其余为零，得 A=1/√(2a)、φ(k) ∝ sin(ka)/k；窄包（a 小）→ φ(k) 宽；宽包 → φ(k) 窄 —— 不确定原理的体现。

关键结论

平面波：ψk = Aeikx，E = ħ²k²/2m，能量连续、任意正。课件红框

两个速度：vp = ħk/2m，vg = ħk/m = vclassical；非相对论下 vp = vg/2。

波包：Ψ = (1/√(2π))∫φ(k)ei(kx−ωt)dk；φ(k) 是动量空间的波函数（傅里叶变换）。

不确定原理：波包越窄，φ(k) 越宽 —— 严格地 σxσp ≥ ħ/2。

易错点

  • 平面波不可归一，不能直接算 ⟨x⟩、σx；必须用波包（或箱归一化）。
  • vp 可以大于 c（非相对论理论里无所谓），但群速度才是信号/粒子速度。
  • k 的符号决定传播方向；E 只依赖 k²，正负 k 能量相同（二重简并）。
  • 方波包的 φ(k) 是 sin(ka)/k 型，不是高斯；高斯包才给出最小不确定乘积。
  • 「自由粒子能量连续」与「束缚态能量分立」的判据是 E 与 V(±∞) 的关系（§2.5 会系统讲）。
§2.5

δ 函数势

✓
▼
原书 §2.5，pp.45–50 · 课件 3-5（p01–p15）

物理图像

V(x) = −αδ(x) 是「极短程相互作用」的模型：一个很窄很深的势阱。它能抓住粒子形成唯一的束缚态；对入射粒子则必有部分反射、部分透射 —— 即使势是排斥的（α<0）也有透射，这就是量子隧穿。

δ 势的价值在于：所有计算都能手算到底，又能演示束缚态与散射态的全套方法。

推导脉络

① 束缚态（E < 0）

  1. 两侧 ψ″ = κ²ψ，κ = √(−2mE)/ħ，解 ψ = Beκx（x<0）、Fe−κx（x>0）；ψ 连续给 F = B。
  2. 在 x=0 积分定态方程，得导数跃变 Δψ′ = −(2mα/ħ²)ψ(0) 代入得 −2Bκ = −2mαB/ħ²，故 κ = mα/ħ²，E = −mα²/2ħ²。
  3. 归一化：2|B|²/κ = 1，B = √(mα)/ħ，故 ψ(x) = (√(mα)/ħ) e−mα|x|/ħ² 只有一个束缚态（无论 α 多大）。

② 散射态（E > 0）

  1. 两侧平面波：Aeikx+Be−ikx（x<0），Feikx（x>0，无左入射）。
  2. 连续性与跃变条件给出 B = iβA/(1−iβ)、F = A/(1−iβ)，β ≡ mα/(ħ²k)。
  3. 反射/透射系数 R = β²/(1+β²)、T = 1/(1+β²) = E/(E + mα²/2ħ²)，满足 R+T=1。

关键结论

唯一束缚态：E = −mα²/2ħ²，ψ = (√(mα)/ħ)e−mα|x|/ħ²（式 2.129 附近，p.45）。课件黑框

散射系数：T = 1/(1 + mα²/(2ħ²E))，R = 1 − T；R+T=1。

重要推论：T 只依赖 α² —— 把阱换成垒（α → −α）透射系数不变，仍有 T>0：量子隧穿。课件★

易错点

  • δ 势只让 一阶导数跃变，波函数本身仍连续；跃变系数是 −2mα/ħ²，别漏 m/ħ²。
  • 束缚态只在 α>0（吸引）时存在；α<0（排斥）没有束缚态，但散射仍会反射。
  • 散射态 E>0 不能归一，只能比较概率流；R、T 是概率流之比，不是波函数模方之比。
  • E → 0 时 T → 0（长波长全部反射）；E 很大时 T → 1（短波长几乎不感受势）。
  • 课件 3-5 有 3 道雨课堂题，其中「δ 函数不连续」类选项是常见陷阱：δ 本身在 0 点发散，但 ∫δ=1。
§2.6

有限深方势阱

✓
▼
原书 §2.6，pp.51–53 · 课件 3-6（p01–p13）

物理图像

把无限深阱的墙降到有限高度 V₀：波函数可以渗入经典禁区并指数衰减，束缚态数目有限（不像无限深阱那样无限多）。阱越浅越窄，束缚态越少；浅到一定程度连一个束缚态都留不住。

同一个势还可以当散射问题处理：入射粒子在某些能量下完全透射（共振），这是量子干涉的结果。把阱换成垒，就得到 STM 的隧穿模型。

推导脉络

① 束缚态（−V₀ < E < 0）

  1. 分区：外区 ψ″ = κ²ψ，κ = √(−2mE)/ħ；内区 ψ″ = −ℓ²ψ，ℓ = √(2m(E+V₀))/ħ。
  2. 偶势 → 取偶/奇解：内部 cos ℓx（偶）或 sin ℓx（奇）；外部指数衰减。
  3. 在边界匹配 ψ 与 ψ′，得超越方程 κ = ℓ tan(ℓa)（偶态）　/　−κ = ℓ cot(ℓa)（奇态）
  4. 令 z = ℓa，z₀ = (a/ħ)√(2mV₀)，化为 tan z = √((z₀/z)² − 1) 用图解法求交点（图 2.17）。
  5. 交点数 = 束缚态数：z₀ < π/2 时只有一个偶束缚态；z₀ → ∞ 回到无限深阱 En ∝ n²。

② 散射（E > 0）与隧穿

  1. 透射系数 T−1 = 1 + [V₀²/(4E(E+V₀))] sin²[(2a/ħ)√(2m(E+V₀))]。
  2. 共振条件：正弦为零 ⇒ En + V₀ = n²π²ħ²/2m(2a)²，此时 T=1（与宽 2a 的无限深阱能级一致）。
  3. 垒（V₀ → −V₀）：T−1 = 1 + [V₀²/(4E(V₀−E))]sinh²(κL)；κL ≫ 1 时 T ≈ [16E(V₀−E)/V₀²] e−2κL

关键结论

束缚态条件：κ = ℓ tan(ℓa)（偶）、−κ = ℓ cot(ℓa)（奇），z₀ = (a/ħ)√(2mV₀)。课件红框

束缚态个数有限：由 z₀ 与 π/2 的比较决定；浅阱可能只剩一个（或零个）。

共振透射：T=1 的条件 E_n+V₀ = n²π²ħ²/2m(2a)²，本质是多重反射相消干涉。

隧穿：T ∝ e−2κL，κ = √(2m(V₀−E))/ħ；STM 电流 I ∝ e−2κL，间距每增加 ~1 Å 电流降一个量级。课件 STM

易错点

  • 有限深阱的束缚态能量以阱底为负值基准（外部 V=0）：−V₀ < E < 0；别把 E 写成正。
  • 偶/奇解要分开处理：偶态用 cos ℓx + tan，奇态用 sin ℓx + cot；混用会得到错误能级。
  • z₀ 的定义里是 V₀ 与阱宽 2a（若用半宽 a）；不同教材记号不同，做题先统一。
  • 「完全透射」只在特定能量发生，不是所有 E 都透射；T=1 与「无势」不同，是干涉效应。
  • STM 的 κ 用功函数 Φ：κ = √(2mΦ)/ħ ≈ 0.512√(Φ/eV) Å⁻¹；别把 V₀−E 写成 V₀。

§3.1

希尔伯特空间

✓
▼
原书 §3.1，pp.62–63 · 课件 4-1（p01–p04）

物理图像

前两章每个势都要从头解一遍微分方程。这一章换一种语言：把波函数看成向量、把算符看成线性变换，量子力学就变成了线性代数 —— 具体势的「偶然性」被抽象掉，剩下的是一般结构（课件：量子力学的天然语言是线性代数）。

「希尔伯特空间」就是允许的波函数全体：平方可积、可归一化的函数集合 L²(a,b)。

要点梳理

  • 态矢量：|α⟩ ↔ a = (a₁, …, a_N)ᵀ；算符：|β⟩ = T|α⟩ ↔ b = Ta。
  • 内积：⟨α|β⟩ = a₁*b₁ + … + a_N*b_N；连续情形 ⟨f|g⟩ = ∫ab f*(x)g(x)dx。
  • 内积的性质：⟨g|f⟩ = ⟨f|g⟩*；⟨f|f⟩ = ∫|f|²dx ≥ 0（等号仅当 f=0）。
  • 正交归一：⟨fm|fn⟩ = δmn（归一 ⟨f|f⟩=1，正交 ⟨f|g⟩=0）。
  • 完备性：希尔伯特空间中任一函数可展开 f = Σcnfn，且 cn = ⟨fn|f⟩。

关键结论

内积：⟨f|g⟩ = ∫f*g dx；归一 ⟨f|f⟩=1；正交 ⟨f|g⟩=0。

完备展开：f = Σcnfn，cn = ⟨fn|f⟩ —— 这就是「投影」。

希尔伯特空间：定义在区间 (a,b) 上、满足 ∫|f|²dx < ∞ 的函数全体（平方可积）。

易错点

  • 内积里是 f*（共轭），不是 f；写 ∫fg 会得到复数甚至在 f=g 时不为正。
  • ⟨f|g⟩ 与 ⟨g|f⟩ 互为共轭，不要当成相等。
  • 完备性是公理（对物理上允许的算符本征函数系成立），不是随便一组函数都完备。
  • 连续谱的本征函数不在希尔伯特空间内（不可归一），但可用 δ 函数归一（§3.3）。
  • 有限维向量与函数空间写法一一对应，但「矩阵」是无穷维的，别把有限维直觉（如行列式）直接搬过来。
§3.2

可观测量与厄密算符

✓
▼
原书 §3.2，pp.64–66 · 课件 4-2（p01–p05）

物理图像

测量结果必须是实数，而量子力学用算符表示可观测量 —— 算符必须满足一个额外条件，才能保证期望值永远是实数。这个条件就是厄密性。

「确定的测量值」对应算符的本征态：若系统处于 Q̂ 的本征态，测 Q 必得本征值、没有涨落。

推导脉络
  1. 期望值 ⟨Q⟩ = ∫ψ*Q̂ψ dx = ⟨ψ|Q̂ψ⟩ 必须为实，即 ⟨ψ|Q̂ψ⟩ = ⟨Q̂ψ|ψ⟩。
  2. 把这条对「一切 f」都要求，就是厄密算符的定义 ⟨f|Q̂f⟩ = ⟨Q̂f|f⟩
  3. 例：动量算符厄密（课件 4-2 p03）：分部积分 ⟨f|p̂g⟩ = ∫f*(−iħ g′)dx = −iħf*g|边界 + ∫(−iħf′)*g dx = ⟨p̂f|g⟩ 边界项在波函数于无穷远趋于零时消失。
  4. 本征方程：若每次测量必得同一值 q，则方差 ⟨(Q̂−q)²⟩=0，即 Q̂Ψ = qΨ Ψ 为本征函数，q 为本征值；全体本征值组成谱，多个本征函数对应同一本征值称为简并。
  5. 例：Q̂ = i d/dφ，周期条件 f(φ+2π)=f(φ)（课件 4-2 p05）：本征值 q = 0, ±1, ±2, …，且非简并。

关键结论

厄密条件：⟨f|Q̂g⟩ = ⟨Q̂f|g⟩（对一切 f, g）⟺ 期望值为实。

确定态 = 本征态：Q̂ψ = qψ，测 Q 必得 q，方差为零。课件方框

算符语言：可观测量 ↔ 厄密算符；本征值 ↔ 可能的测量值；本征态 ↔ 测量后坍缩到的态。

易错点

  • 厄密性是 ⟨f|Q̂g⟩ = ⟨Q̂f|g⟩，注意「算符作用在哪一边」；写成 Q̂ 在右边/左边搞反会导致共轭错误。
  • 分部积分时边界项必须为零，否则算符不厄密；动量算符的厄密性就依赖这一点。
  • 「本征值都是实数」是本征函数的性质（§3.3 才证），此处先记住；不要反过来推「实算符都厄密」。
  • 测量后坍缩到对应本征态，但本征态不唯一（简并时），需要额外的投影规则。
  • Q̂ 本身不是数，不能写成 ⟨ψ|Q̂|ψ⟩ = Q̂⟨ψ|ψ⟩；算符要作用在右边的函数上。
§3.3

厄密算符的本征函数

✓
▼
原书 §3.3，pp.67–70 · 课件 4-3（p01–p08）

物理图像

厄密算符的本征函数有三条「金科玉律」：实本征值（测量结果实）、不同本征值对应本征函数正交（不同确定态互斥）、完备（任何态都能由它们展开）。§3.4 的概率诠释全部建立在三条之上。

离散谱与连续谱的区别在于：前者可归一、在希尔伯特空间里；后者不可归一，只能用 δ 函数「正交归一」。

推导脉络
  1. 定理 1（实性）：设 Q̂f = qf 且 Q̂ 厄密，则 q⟨f|f⟩ = ⟨f|Q̂f⟩ = ⟨Q̂f|f⟩ = q*⟨f|f⟩ 故 q = q*，本征值为实。
  2. 定理 2（正交性）：设 Q̂f = qf、Q̂g = q′g，q ≠ q′。由厄密性得 q′⟨f|g⟩ = ⟨f|Q̂g⟩ = ⟨Q̂f|g⟩ = q⟨f|g⟩ 故 (q′−q)⟨f|g⟩ = 0 ⟹ ⟨f|g⟩ = 0。
  3. 完备性（公理）：希尔伯特空间中任一函数可展开为 f = Σcnfn。
  4. 例 1（动量，课件 p05）：−iħf′ = pf ⟹ fp = (1/√(2πħ))eipx/ħ，⟨fp′|fp⟩ = δ(p−p′)（狄拉克正交归一）。
  5. 例 2（位置，课件 p07）：xgy = ygy ⟹ gy = δ(x−y)，⟨gy′|gy⟩ = δ(y−y′)。

关键结论

三性质：本征值实、不同本征值对应本征函数正交、本征函数系完备。

离散谱：⟨fm|fn⟩ = δmn，可归一。连续谱：⟨fz′|fz⟩ = δ(z−z′)，不可归一。

动量本征函数：fp = (2πħ)−1/2eipx/ħ；位置本征函数：gy = δ(x−y)。课件例题

展开：f = ∫c(p)fpdp 就是傅里叶变换；c(p) = ⟨fp|f⟩。

易错点

  • 简并时不同本征函数未必自动正交，需要用 Gram-Schmidt 再正交化。
  • 连续谱本征函数「不可归一」不等于「不能用」：用 δ 函数归一，展开式写成积分。
  • 本征值相同不代表函数相同；本征函数乘任意常数仍是本征函数（归一化只定模长）。
  • 「实性」是对厄密算符说的；非厄密算符（如 d/dx 不带 −iħ）可以有复本征值。
  • 位置本征函数 δ(x−y) 不是普通函数，积分时要小心；它只用于形式推导，不代表物理态。
§3.4

广义统计诠释

✓
▼
原书 §3.4，pp.71–72 · 课件 4-4（p01–p05）

物理图像

§1.2 只说了「位置的统计诠释」；有了本征函数系之后，可以把同一句话推广到任何可观测量：把态按 Q̂ 的本征函数展开，展开系数的模方就是测到对应本征值的概率。

这就是「广义统计诠释」，也是量子力学「测量」的标准表述：概率由投影给出，测量后态坍缩到相应本征态。

推导脉络
  1. 把态展开：Ψ = Σcnfn，由正交性 cn = ⟨fn|Ψ⟩ = ∫fn*Ψdx。
  2. 归一化条件给出 Σ|cn|² = 1（交叉项因正交而消失）。
  3. 概率诠释：测量 Q 得 qn 的概率为 |cn|²；测量后态坍缩为 fn。
  4. 期望值：⟨Q⟩ = Σqn|cn|²（加权平均）。
  5. 连续谱：Ψ = ∫c(z)fzdz，c(z) = ⟨fz|Ψ⟩，落在 dz 内的概率为 |c(z)|²dz。
  6. 特例：位置表象 c(y) = Ψ(y)、概率 |Ψ|²dy；动量表象 Φ(p) = (2πħ)−1/2∫e−ipx/ħΨdx、概率 |Φ|²dp。

关键结论

广义统计诠释：P(qn) = |cn|²，cn = ⟨fn|Ψ⟩；连续谱 P(z) = |c(z)|²dz。

归一与期望：Σ|cn|² = 1，⟨Q⟩ = Σqn|cn|²。课件公式 (21)–(24)

课件例题（4-4 p05）：δ 阱束缚态 Ψ ∝ e−mα|x|/ħ²，动量空间波函数为洛伦兹型，算得 P(p>p₀) = 1/4 − 1/2π ≈ 0.0908。

易错点

  • cn 是复数，概率是 模方 |cn|² = cncn*，不是 cn 本身。
  • 「测到某本征值的概率」要求本征函数正交归一；若基不正交，公式要加重叠矩阵。
  • 连续谱给的是概率密度，问「恰好等于某值」的概率为零，只能问区间。
  • 本征值简并时，测到该本征值的概率是各简并态 |cn|² 之和。
  • 测量会改变态（坍缩），所以「连续测两次同一量」的联合概率不能直接用第一次的 |cn|² 相乘（除非两次测量对易）。
§3.5

不确定原理（一般形式）

✓
▼
原书 §3.5，pp.73–78 · 课件 4-5（p01–p09）

物理图像

§1.6 的不确定关系是「类比 + 直觉」得到的；这一节用施瓦茨不等式给出严格证明，并推广到任意两个可观测量：不确定度的乘积由它们对易子的期望值控制。

对易的两个量可以同时确定；不对易的两个量（如 x 与 p）不能有共同本征态 —— 这是「不相容可观测量」的精确含义。

推导脉络
  1. 令 f = (Â−⟨A⟩)Ψ，g = (B̂−⟨B⟩)Ψ，则 σA² = ⟨f|f⟩，σB² = ⟨g|g⟩。
  2. 施瓦茨不等式 ⟨f|f⟩⟨g|g⟩ ≥ |⟨f|g⟩|²，即 σA²σB² ≥ |⟨f|g⟩|²。
  3. 对任意复数 z，|z|² ≥ (Im z)² = [(z−z*)/2i]²；取 z = ⟨f|g⟩，得 σA²σB² ≥ (⟨[Â,B̂]⟩/2i)² 即 σAσB ≥ |⟨[Â,B̂]⟩|/2（广义不确定原理）。
  4. 取 Â = x、B̂ = p̂，由 [x̂,p̂] = iħ 得 σxσp ≥ ħ/2。
  5. 最小不确定波包：取等号要求 g = iaf（a 实），解出高斯型 Ψ ∝ e−a(x−⟨x⟩)²/2ħei⟨p⟩x/ħ。
  6. 能量-时间：由 d⟨Q⟩/dt = (i/ħ)⟨[Ĥ,Q̂]⟩ + ⟨∂Q̂/∂t⟩ 出发，令 ΔE = σH、Δt = σQ/|d⟨Q⟩/dt|，得 ΔEΔt ≥ ħ/2。

关键结论

广义不确定原理：σAσB ≥ |⟨[Â,B̂]⟩|/2（式 3.62，p.73）。课件方框

位置-动量：[x̂,p̂] = iħ ⟹ σxσp ≥ ħ/2。

最小波包：高斯型；取等号条件 g = iaf。

能量-时间：ΔEΔt ≥ ħ/2；Δt 定义为态发生显著变化所需时间，不是某个「时间算符」的标准差。

守恒量：若 [Ĥ,Q̂]=0 且 Q̂ 不显含 t，则 d⟨Q⟩/dt = 0。

易错点

  • 对易子的符号：[x̂,p̂] = iħ（不是 −iħ，取决于算符定义与顺序，本课程统一用 p̂=−iħ∂ₓ）。
  • ΔEΔt ≥ ħ/2 中的 Δt 不是「测量时间」的普适下限，而是该态演化的特征时间；定态 ΔE=0 时 Δt=∞。
  • 取等号需要波包为高斯型，且两算符的「中心化」满足 g = iaf；普通态乘积更大。
  • 对易只是「可同时精确」的必要条件；还要考虑简并与共同本征函数系。
  • 课件 4-5 的例题算得 ΔEΔt = 2πħ（两能级叠加的振荡周期），与 ħ/2 不矛盾：那是最小下限，具体态的乘积可以更大。
§3.6

狄拉克符号

✓
▼
原书 §3.6，pp.79–87 · 课件 4-6（p01–p08）

物理图像

把「态是向量」这件事写得彻底一点：态记作 ket |α⟩，它的共轭记作 bra ⟨α|，内积就是它们的「括号」 ⟨α|β⟩。波函数只是态在某个基下的分量，比如 Ψ(x,t) = ⟨x|S(t)⟩。

这样写的好处：算符像矩阵、展开像基变换、完备性像单位分解 —— 量子力学与线性代数完全同构，且与具体表象无关。

推导脉络
  1. 态与内积：|α⟩ ↔ (a₁,…,a_N)ᵀ，⟨α| ↔ (a₁*,…,a_N*)；⟨α|β⟩ = Σai*bi；⟨β|α⟩ = ⟨α|β⟩*。
  2. 算符：|β⟩ = Q̂|α⟩；在基 |en⟩ 下，an = ⟨en|α⟩，矩阵元 Qmn = ⟨em|Q̂|en⟩，于是 bm = ΣQmnan。
  3. 基与完备性：⟨em|en⟩ = δmn ⟹ |α⟩ = Σ⟨en|α⟩|en⟩，即 Σn|en⟩⟨en| = 1 连续基：∫|ez⟩⟨ez|dz = 1。
  4. 投影算符：P̂ = |α⟩⟨α|，P̂|β⟩ = (⟨α|β⟩)|α⟩ —— 把任意态投到 |α⟩ 方向。
  5. 课件例题（4-6 p04–p06）：两态系统 H = [[h,g],[g,h]]，初态 |1⟩，求得 E± = h ± g、|S±⟩ = (1/√2)(1,±1)ᵀ，最终 |S(t)⟩ = e−iht/ħ(cos(gt/ħ), −i sin(gt/ħ))ᵀ。

关键结论

基本规则：⟨α|β⟩ = ⟨β|α⟩*；⟨α|α⟩ ≥ 0；算符作用在 ket 上得 ket，作用在 bra 上得 bra（左作用）。

矩阵表示：Qmn = ⟨em|Q̂|en⟩，bm = ΣQmnan。

完备性关系：Σ|en⟩⟨en| = 1（离散）；∫|ez⟩⟨ez|dz = 1（连续）。课件 p08

表象无关：Ψ(x,t) = ⟨x|S(t)⟩，Φ(p,t) = ⟨p|S(t)⟩，cn = ⟨n|S(t)⟩ —— 都是同一个 |S⟩ 在不同基下的分量。

易错点

  • ⟨α|β⟩ 是复数，⟨α|β⟩* = ⟨β|α⟩；别写成 ⟨α|β⟩ = ⟨β|α⟩。
  • 算符作用在 bra 上时要「向左作用」：⟨α|Q̂ 是合法的，但 Q̂|α⟩⟨β| 是算符而非数。
  • |α⟩⟨β| 是算符（外积），⟨β|α⟩ 是数（内积），两者不能混。
  • 完备性关系里的 1 是单位算符，不是归一化常数；插在任意两态之间可做基变换。
  • 连续谱的完备性用积分与 δ 归一，离散谱用求和与 δmn；混用会丢失 δ 函数因子。

类型 A：归一化与概率计算 基本功

识别特征：给出 Ψ(x,0)，要求定归一化常数、区间概率、最可几位置。
  • 三步：写 ∫|Ψ|²dx = 1 定常数 → 求 P(a≤x≤b) = ∫ab|Ψ|²dx → 需要时求 ⟨x⟩。
  • 分段函数逐段积分，边界点单独处理；常数的正负号由归一化只定模长，相位可任取。
  • 代表题：习题 1.2–1.5、1.17；课件 2-3 例题（p08）、1-2 落体例题。
  • 易错：漏掉常数因子；把 |Ψ|² 当概率而非概率密度；区间外积分不写零。

类型 B：期望值与不确定度

识别特征：求 ⟨x⟩、⟨x²⟩、⟨p⟩、⟨p²⟩、σx、σp，或验证不确定关系。
  • 公式：⟨x⟩ = ∫Ψ*xΨdx，⟨p⟩ = ∫Ψ*(−iħ∂ₓ)Ψdx，σA² = ⟨A²⟩−⟨A⟩²。
  • ⟨p⟩ 不要用 m d⟨x⟩/dt 硬算（除非题目要求验证 Ehrenfest 定理）；直接做导数更稳。
  • 代表题：习题 1.1–1.18 中的期望值小题、2.41（谐振子）、课件 2-4/2-5 例题。
  • 易错：算符作用对象；Ψ* 漏共轭；σ 写成 σ²；积分限与归一化不符。

类型 C：定态与含时叠加

识别特征：给初态，求 Ψ(x,t)、|Ψ|² 的时间依赖、能量期望。
  • 先求定态 ψn 与 En，再展开 cn = ∫ψn*Ψ(0)dx，最后 Ψ = Σcnψne−iEnt/ħ。
  • 两态叠加会出现拍频 |E₂−E₁|/ħ；概率密度随时间振荡（课件 3-1 例题）。
  • 代表题：习题 2.7–2.9、2.37；课件 3-1 S10、3-2 S10。
  • 易错：把叠加态当定态；cn 忘了取共轭；Σ|cn|²≠1 时没检查。

类型 D：一维无限深方势阱 最常考

识别特征：盒子势、给宽度 a，求能级/波函数/概率/节点。
  • 直接套 ψn = √(2/a)sin(nπx/a)，En = n²π²ħ²/2ma²；注意 n≥1。
  • 节点数 n−1；宇称相对 a/2；E∝n² 非等间距。
  • 代表题：习题 2.4–2.9、2.37、2.40；课件 3-2 全节 + S10 例题。
  • 易错：n=0；边界条件写成 ψ′(0)=0；忘记归一化常数 √(2/a)。

类型 E：谐振子

识别特征：抛物线势、升降算符、零点能、⟨V⟩ 或 ⟨T⟩。
  • 能级 En = (n+½)ħω，ω = √(k/m)；基态高斯型。
  • 用 x = √(ħ/2mω)(a++a−) 与 a±ψn = √(n+1 或 n)ψn±1 算矩阵元。
  • 结论：⟨V⟩ = ⟨T⟩ = ½En（位力定理）。
  • 代表题：习题 2.41 及章末谐振子题；课件 3-3 例题。
  • 易错：漏零点能；a± 的系数 √(n+1)/√n；n=0 时 a−ψ0=0。

类型 F：自由粒子与波包

识别特征：平面波、连续谱、群速度/相速度、傅里叶变换、方波包。
  • 平面波 ψ = Aeikx，E = ħ²k²/2m；不可归一，需用波包 ∫φ(k)ei(kx−ωt)dk。
  • vp = ħk/2m，vg = ħk/m = vclass；非相对论 vp = vg/2。
  • 代表题：习题 2.43（高斯波包）、2.52（散射矩阵，延伸）；课件 3-4 方波包例题。
  • 易错：对平面波直接算 ⟨x⟩；把 vp 当粒子速度；傅里叶变换系数漏 1/√(2π)。

类型 G：δ 函数势

识别特征：V = −αδ(x)，求束缚态能量、波函数、透射/反射系数。
  • 束缚态：κ = mα/ħ²，E = −mα²/2ħ²，ψ = (√(mα)/ħ)e−mα|x|/ħ²；只有一个束缚态。
  • 散射：β = mα/(ħ²k)，T = 1/(1+β²)，R = β²/(1+β²)，R+T=1。
  • 跃变条件：Δψ′ = −(2mα/ħ²)ψ(0)。
  • 代表题：习题 2.30、2.31；课件 3-5 全节。
  • 易错：把 δ 势当普通势在 0 点求导；忘记跃变；T 与 α 符号无关（垒也有透射）。

类型 H：有限深阱与隧穿

识别特征：有限深 V₀、求束缚态数/能级、散射共振、STM。
  • 写出分区解 → 匹配 ψ、ψ′ → 偶态 κ=ℓtan(ℓa)、奇态 −κ=ℓcot(ℓa)。
  • 图解法：z=ℓa、z₀=(a/ħ)√(2mV₀)；交点数即束缚态数。
  • 散射/共振：T=1 条件 E_n+V₀ = n²π²ħ²/2m(2a)²；垒的透射 T∝e−2κL。
  • 代表题：习题 2.29、2.32、2.33；课件 3-6 全节（含 STM 估算）。
  • 易错：束缚态能量区间写错；偶/奇方程混用；STM 里 κ 用功函数而非 V₀−E。

类型 I：厄密性与本征值

识别特征：证明某算符厄密、求本征值/本征函数、判断简并。
  • 厄密：证 ⟨f|Q̂g⟩ = ⟨Q̂f|g⟩（分部积分 + 边界项为零）。
  • 本征方程 Q̂f = qf；实本征值、正交、完备三性质。
  • 代表题：习题 3.1–3.8 一类；课件 4-2 动量厄密性、4-3 动量/位置本征函数。
  • 易错：分部积分边界项；算符定义域；简并时没正交化。

类型 J：广义统计诠释

识别特征：求测得某本征值的概率、cn、期望值。
  • cn = ⟨fn|Ψ⟩，P(qn) = |cn|²，⟨Q⟩ = Σqn|cn|²。
  • 连续谱用 |c(z)|²dz；位置/动量空间波函数互相傅里叶变换。
  • 代表题：习题 3.4–3.6 一类；课件 4-4 δ 阱例题（0.0908）。
  • 易错：概率不是 cn；简并求和；连续谱问区间。

类型 K：对易子与不确定原理

识别特征：算 [A,B]、证不确定关系、求最小波包、能量-时间。
  • 基本对易子 [x̂,p̂]=iħ；由此推出 σAσB ≥ |⟨[A,B]⟩|/2。
  • 最小波包条件 g = iaf，得高斯型；能量-时间 ΔEΔt ≥ ħ/2。
  • 代表题：习题 3.17–3.20、3.39；课件 4-5 全节。
  • 易错：对易子符号；Δt 的含义；把「取等」当普遍成立。

类型 L：狄拉克符号与矩阵

识别特征：用 |α⟩、⟨α| 表示，求矩阵元、投影、本征矢。
  • 内积 ⟨α|β⟩、矩阵元 Qmn=⟨em|Q̂|en⟩、完备性 Σ|en⟩⟨en|=1。
  • 两态问题：写矩阵 → 解特征方程 → 归一化本征矢 → 加时间因子。
  • 代表题：课件 4-6 两态例题；习题 3.39–3.40。
  • 易错：内积共轭；外积与内积混淆；连续谱的 δ 归一。

类型 M：概念辨析与课件互动题

识别特征：判断/简答/多选，考「说法是否正确」。
  • 高频判断点：定态是否「静止」；叠加态概率密度是否随时间变；平面波能否归一；n=0 是否存在；零点能是否为零；R+T 是否等于 1；隧穿与势垒符号。
